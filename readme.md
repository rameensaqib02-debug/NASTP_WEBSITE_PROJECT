# NASTP Space Sustainability Centre Website

A responsive multi-page website developed for the **NASTP Space Sustainability Centre** as part of an **internship task**.

## About the Project

This project was developed as an internship assignment to create a professional website for the NASTP Space Sustainability Centre.

The website presents information about the centre, its services, teams, and other space-related content through a multi-page web interface.

## Internship Task

This website was created as part of an **internship task**, providing practical experience in:

- Web development
- HTML and CSS
- JavaScript
- Responsive website design
- Multi-page website development
- Organizing website assets and media
